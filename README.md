# 🚀 AVINYA – The Future of Innovation

### Achieving Harmony Through Innovation | Technika 6.0 – Web Wizard

**AVINYA** is a modern, futuristic and responsive website developed for the Web Wizard competition at Technika 6.0. The project represents the theme of innovation, creativity and technology through an attractive user interface and interactive features.

Our goal is to create a digital platform that brings different technical events together in one place and provides users with a smooth and engaging browsing experience.

---

## 🌟 Project Overview

AVINYA is designed with a futuristic interface featuring dark backgrounds, neon colors, animated elements and interactive sections. It provides information about technical events and allows users to explore events and submit registration details.

The website focuses on creativity, usability, responsiveness and modern web design.

## ✨ Key Features

- **Modern UI/UX:** Futuristic design with neon colors and attractive animations.
- **Responsive Design:** Works on desktops, tablets and mobile devices.
- **Event Explorer:** Browse different technical events in one place.
- **Search Functionality:** Search for events by name.
- **Category Filter:** Filter events according to their categories.
- **Event Details:** View event information through interactive pop-up windows.
- **Registration Form:** Submit participant details and select an event.
- **Local Storage:** Store registration details in the browser.
- **Dark/Light Mode:** Switch between different website themes.
- **Interactive Navigation:** Easy navigation between website sections.
